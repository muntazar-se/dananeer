# دنانير (Dananir) — منصة التجارة الإلكترونية لتجار Instagram في العراق

> **«من حساب إنستا… إلى متجر إلكتروني كامل»**  
> **«من دينار… إلى دنانير!»**

صفحة هبوط وأنظمة تجارة إلكترونية احترافية ومكتملة لمنتج **دنانير (Dananir)**، المصمم خصيصاً لمساعدة تجار إنستغرام في العراق على تحويل نشاطهم التجاري من الرسائل اليدوية (DMs) والتعليقات إلى متجر إلكتروني متكامل لإدارة المنتجات، الطلبات، المخزون، والزبائن باشتراك سنوي واضح ودون أي عمولة على المبيعات (0%).

---

## 🚀 التقنيات المعمارية والسحابية (Free Tiers)

تم بناء المشروع بالكامل ليعمل بأعلى كفاءة اعتماداً على **الباقات المجانية (Free Tiers)** للخدمات السحابية:

| الخدمة السحابية | الدور في النظام | الباقة المجانية (Free Tier) |
|---|---|---|
| **Vercel** | استضافة ونشر الصفحة وServerless Functions | مجاناً للأبد، نشر تلقائي من مستودع GitHub |

| **Cloudflare R2** | تخزين سحابي لصور المنتجات والشعارات (S3-compatible) | 10GB تخزين مجاني، 0 رسوم نقل بيانات (Egress) |
| **Next.js 16 + React 19** | إطار العمل وهندسة الواجهات والأداء (App Router) | فائق السرعة، متوافق مع معايير SEO وCore Web Vitals |
| **Vanilla CSS Architecture** | تصميم وهوية بصرية مخصصة RTL بالكامل | لا يعتمد على فئات Tailwind الافتراضية، أداء CSS خام نقي |

1. **الترويسة العلوية (Sticky Navigation):** شعار دنانير المطور، روابط سريعة، وزر الدعوة للعمل `ابدأ متجرك`.
2. **الواجهة الرئيسية (Hero Section):** العنوان الأساسي: «من حساب إنستا… إلى متجر إلكتروني كامل» وشعار «من دينار… إلى دنانير!» مع محاكاة بصرية للمتجر ولوحة التحكم وإشعار الطلبات المباشرة.
3. **شريط الثقة والقيمة السريعة (Trust Strip):** 4 ركائز موثوقة: متجر احترافي، لوحة تحكم سهلة، إدارة الطلبات، اشتراك سنوي واضح.
4. **المشكلة (The Problem):** محاكاة واقعية لرسائل الـDM والأسئلة المتكررة وتشتت المنشورات ومحدودية تجربة الشراء.
5. **التحول (The Transformation):** مقارنة مرئية للمسار القديم المجهد مقابل مسار دنانير الآلي السلس.
6. **كيف يعمل؟ (How it Works):** 3 خطوات واضحة (أنشئ متجرك، أضف منتجاتك، شارك رابط متجرك).
7. **المميزات الأساسية (Core Features):** 8 كروت تفاعلية تغطي المتجر، إدارة الطلبات، المنتجات، العملاء، المؤشرات، الهاتف، الرابط الخاص، وسهولة الإدارة.
8. **استعراض لوحة التحكم (Dashboard Showcase):** نافذة متصفح تفاعلية تعرض مبيعات اليوم، جدول طلبات زبائن بغداد والمحافظات وحالات التوصيل.
9. **معرض المتاجر (Store Showcase):** نماذج حقيقية لمتاجر أزياء، عطور، مجوهرات، وحرف يدوية مع تجربة حية.
10. **تجربة الهاتف المحمول (Mobile Experience):** استعراض حقيقي لسرعة الطلب وسلة الشراء على أجهزة الهواتف الذكية.
11. **لماذا دنانير؟ (Why Dananir):** 5 أسباب جوهرية (مصمم لتاجر Instagram، بسيط، احترافي، واضح، محلي).
12. **الأسعار (Pricing):** خطة واضحة ومحددة: **350,000 د.ع للسنة الأولى** و **90,000 د.ع سنويًا للتجديد** و 0% عمولة على المبيعات.
13. **قصص المتاجر والتجار:** تجارب حقيقية لنماذج المتاجر الحية.
14. **الأسئلة الشائعة (FAQ Accordion):** 10 أسئلة وإجابات شفافة ومباشرة تغطي كافة استفسارات التاجر.
15. **الدعوة الختامية للعمل (Final CTA):** ختام بصري مؤثر ومحفز للبدء.

## 🛠️ التثبيت والتشغيل محلياً

```bash
# استنساخ المستودع
git clone https://github.com/muntazar-se/dananeer.git
cd dananeer

# تثبيت الحزم
npm install

# إعداد ملف البيئة
cp .env.example .env.local

# تشغيل خادم التطوير
npm run dev
```

افتح المتصفح على: `http://localhost:3000`

## 🗄️ إعداد Supabase (قاعدة البيانات المجانية)

1. افتح حساباً مجانياً على [Supabase.com](https://supabase.com).
2. أنشئ مشروعاً جديداً (مثلاً: `dananeer-prod`).
3. توجه إلى **SQL Editor** والصق محتوى الملف الموجود في:
   `supabase/schema.sql`
4. اضغط **Run**. سيتم إنشاء جدول `merchant_leads` مع الفهارس وسياسات الحماية (Row Level Security).
5. انسخ كلاً من `Project URL` و `anon public key` وضعها في `.env.local` أو متغيرات Vercel:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGci...
   ```

## ☁️ إعداد Cloudflare R2 (التخزين المجاني)

1. في لوحة تحكم [Cloudflare](https://dash.cloudflare.com)، ادخل على **R2 Object Storage**.
2. أنشئ Bucket جديد باسم `dananir-assets`.
3. أنشئ **API Token** بصلاحيات قراءة وكتابة (Object Read & Write).
4. أضف المفاتيح إلى متغيرات البيئة:
   ```env
   CLOUDFLARE_R2_ACCOUNT_ID=your_account_id
   CLOUDFLARE_R2_ACCESS_KEY_ID=your_access_key
   CLOUDFLARE_R2_SECRET_ACCESS_KEY=your_secret_key
   CLOUDFLARE_R2_BUCKET_NAME=dananir-assets
   ```

## 🌐 النشر على Vercel (Free Tier)

1. اربط المستودع في حسابك على [Vercel](https://vercel.com).
2. أضف متغيرات البيئة من `.env.example`.
3. اضغط **Deploy**. سيتولى Vercel البناء والنشر التلقائي مع شهادة SSL مجانية وحماية CDN عالمية.
